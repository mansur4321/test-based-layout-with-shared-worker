# Проект: Тестовое задание для Арлайт РУС (HTML/CSS/JS + Shared Worker)

Минимальный setup без сборки: только статические файлы и запуск через локальный HTTP-сервер.

## Требования

- Любой современный браузер с поддержкой `SharedWorker`
- Локальный HTTP-сервер

## Быстрый запуск

### Вариант 1: Node.js (Используемый мной)

```powershell
npx serve . -l 5500
```

Откройте в браузере:
`http://localhost:5500`

### Вариант 2: Live Server (VS Code) (Хватит чтобы проверить вёрстку)

- Установите расширение **Live Server**
- Запустите сервер из корня проекта
- Откройте локальный URL, который покажет расширение

## Функционал

### Форма подписки

- Проверка email на валидность
- Сохранение email в список подписчиков и его отображение
- Сворачивание и раскрывание полного списка подписчиков при N > 5 (N - кол-во подписчиков)
- Сохранение списка подписчиков в LocalStorage

### Смена темы

- Возможность установить тему либо "Темную", либо "Светлую"
- Синхронизация темы через Shared Worker во всех вкладках приложения

### Отображение кол-ва открытых вкладок приложения

- Синхронизация кол-ва вкладок через Shared Worker
